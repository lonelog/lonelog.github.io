Lonelog

A Standard Notation for Solo RPG Session Logging

v1.5.0

Lonelog is a lightweight shorthand language designed to separate mechanics from fiction, stay compact at the table, and scale seamlessly from quick one-shots to sprawling campaigns.

Quick Start Example

Core Philosophy

  • Format-agnostic: Works identically in digital Markdown code blocks or analog paper notebooks.
  • Toolbox, not a rulebook: Fully modular. Use the five core symbols or layer in tracking elements (Clocks, Threads, NPC tags) as needed.
  • Built for scannability: Standardised tokens allow external tools, plugins, or human readers to parse session logs at a glance.
